# AI EDU 1.0 и AI EDU 2.0

## AI EDU 1.0 / LessonAi
- Streamlit-интерфейс.
- Старый проект остаётся неизменным.
- Конкретные доступные функции подтверждаются реальными кадрами опубликованной версии.

## AI EDU 2.0
- Next.js и FastAPI.
- Отдельная авторизация и пользовательские данные.
- Загрузка DOCX/PDF/XLSX РУП.
- Проверка и редактирование извлечённых данных.
- Занятие с lesson_id и четырьмя отдельными материалами.
- Видимый многоагентный workflow: Координатор, Методист, Креативщик, Ассистент по оцениванию.
- Реальный LLM API с явной ошибкой при отсутствии конфигурации.
- Редактирование, скачивание DOCX/PPTX и retry.
- Supabase/Auth/Storage модель и миграции с RLS.

## Статус доказательств
Сравнительные выводы должны опираться на реальные пользовательские кадры и рабочие HTTP/LLM проверки, а не на обещания интерфейса.
